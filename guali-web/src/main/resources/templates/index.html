    ¿Cómo usar Guali Dev?
    
        
    
            
    1. Abre una lección
    
            
    Menú Lección → Abrir lección. A la izquierda verás la explicación y el código que debes escribir. Arriba aparece el objetivo de la lección.
    
            
    2. Escribe el código a mano
    
            
    En el editor de la derecha. Pegar está deshabilitado a propósito: escribir el código te ayuda a memorizar la sintaxis y a entender los errores.
    
            
    3. Compila y ejecuta
    
            
      
                
    • Compilar (o Ctrl+Enter): revisa tu código. Los errores aparecen en la consola con el número de línea.
      • 
                
    • Ejecutar: solo se habilita si la última compilación fue exitosa. Si cambias el código, debes compilar otra vez.
      • 
            
    
            
    4. Cumple el objetivo
    
            
    
                
    ObjetivoSe completa cuando…
    
                
                
    Compilar con erroral compilar aparece al menos un error
    
                
    Compilar exitosoal compilar hay 0 errores
    
                
    Ejecutar con errorcompila bien pero falla al ejecutar
    
                
    Ejecutar exitosocompila y se ejecuta sin errores
    
                    
            
    
            
    5. Revisa tu historial
    
            
    Menú Historial → Ver historial: cada vez que abres una lección queda registrada como Completada o Pendiente.
    
            
    Configuración
    
            
    En Configuración puedes cambiar el tamaño de letra y el tema claro u oscuro. Se recuerda en este navegador.
    
            
    Limitaciones del compilador
    
            
      
                
    • No se puede leer del teclado (Scanner): el programa no recibe entrada.
      • 
                
    • Todo el código debe estar en un solo archivo y sin librerías externas.
      • 
                
    • Un programa que tarde más de 10 segundos se detiene automáticamente.
      • 
                
    • Puedes usar Java 25 compacto (void main()) o una clase con public static void main.
      • 
            
    
        
    
        
    
    
    
    


    
    
        
    Acerca de Guali Dev
    
        
    
            
    Aplicación para practicar programación introductoria en Java mediante lecciones cortas, sin asistencia de herramientas externas.
    
            
    Proyecto del curso Desarrollo Web · Universidad Mariano Gálvez de Guatemala.
    
                Compilación y ejecución con la librería guali-dev 1.0.0.
    
        
    
        
    
    
    
    


    
        
    
            
    Importar compendio de lecciones
    
            
    
                
    Selecciona un archivo .zip con una carpeta por lección. Cada carpeta debe tener leccion.md, config.txt y, opcionalmente, imágenes. Si una lección ya existe (mismo nombre de carpeta) se reemplaza.
    
                
                
    
            
    
            
    
                
                
            
    
        
    
        

    
        
    
            
    Eliminar una lección
    
            
    
                
    La lección se borra de la base de datos. El historial de los estudiantes se conserva.
